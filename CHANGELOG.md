## 0.6.0 — 26 November 2026 (First public release candidate)

- **Zero-friction packaging, CI Action, and pre-commit adoption:** Added zero-dependency Python packaging (`pyproject.toml` exposing `anti-slop-diff`, `anti-slop-hook`, and `anti-slop-api` console entry points for one-line `uvx` execution without cloning), reusable composite GitHub Action (`action.yml`), `.pre-commit-hooks.yaml`, `--no-budget` mode in `gates/diff_check.py`, one-command `--install claude|antigravity|codex` (with `--dry-run` and automatic `*.bak-antislop` backups) in `gates/hooks/run_diff_gate_hook.py`, portable hook examples across external repositories, plus `SECURITY.md` and `THIRD_PARTY_LICENSES.md`.
- **Benchmark isolation and pre-hash privacy sanitization (`scripts/run_benchmark.py`, `scripts/check.py`):** Added per-run isolated `CODEX_HOME` (minimal auth only; zero personal `~/.codex/skills/`, rules, hooks, or configs) and deterministic pre-hash path/username sanitization across traces, outputs, and workspace diffs before SHA-256 hashing; preserved the frozen `v0.1.0` core-rules snapshot independently of `results/`; updated `scripts/check.py` to validate `pilot-v0.6.0.json` and clean empty `results/` trees.
- **Flagship clean `n = 3` public benchmark (`results/pilot-3way-v0.6.0/`, `LOCAL-05`):** Executed and published the first `CODEX_HOME`-isolated, pre-hash-sanitized public dataset (`144` runs across 4 focus models × `RW3`/`RW5`/`RW6`/`SE2` × 3 conditions × `n = 3`; `142` completed, `2` `720s` timeouts kept in denominators; `0` workstation/skill/username leaks; deterministic checks mechanically verified via `benchmarks/graders/grade_rw3.py`, frozen-test `git diff`, read-only checks, and `inspect_text_constraints`; semantic rubric checks scored via isolated LLM-assisted per-case verbatim audit passes committed under `results/pilot-3way-v0.6.0/reviews/`): overall **`31/48` (`64.6%`) -> `40/48` (`83.3%`) -> `43/48` (`89.6%`, `+12/-0` vs. baseline)**, pinned OSS `origin: real_work` **`22/36` (`61.1%`) -> `30/36` (`83.3%`) -> `34/36` (`94.4%`)**, strict `wc -w` **`26/48` -> `37/48` -> `42/48`**, `RW3` frozen-test tampering cut from **`8/11` (`72.7%`)** baseline to **`0/23` (`0.0%`)** across ruled arms, and Opus matched lexical words cut `-31.6%` at `-6.9%` USD under `D-OPU-4` (while exposing Opus's unmitigated `8/9` `SE2` Stage 2 deferral/pytest-only verification limit). Archived the four pre-public `n = 1` internal diagnostics (`LOCAL-01`–`LOCAL-04`, 348 runs) privately off the public repository because pre-public Codex runs lacked `CODEX_HOME` isolation.
