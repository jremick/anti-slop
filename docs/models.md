# Model profiles

These profiles document verified capabilities, failure modes, API integration traps and candidate controls for the five target models. They are not a ranking of how much slop each model produces.

**Evidence checked:** 28 November 2026 for clean `v0.9.0` spec-fidelity pilot (`LOCAL-10`); 27 November 2026 for external vendor and research sources (`OAI-*`, `ANT-*`, `GOO-*`, `EXT-01`–`EXT-15`) and clean `v0.7.0`/`v0.8.0` public benchmarks (`LOCAL-06`–`LOCAL-09`); 26 November 2026 for archived pre-public internal diagnostics (`LOCAL-01`–`LOCAL-04`) and the clean `v0.6.0` public benchmark (`LOCAL-05`). **Local benchmark status:** Six clean, `CODEX_HOME`-isolated, pre-hash-sanitized `n = 3` public datasets (`324` runs across 4 focus models; `claude-fable-5-2` remains excluded pending `D-FAB-4` revision) are published under `results/`: [pilot-spec-fidelity-v0.9.0/](../results/pilot-spec-fidelity-v0.9.0/README.md) (`LOCAL-10`, `SE3`, `36` runs / `72` stages: `12/12` accuracy ceiling across all 3 arms, Opus `model-controls` `+48.5%` USD / `+71.2%` tokens keeping `D-OPU-5` task-scoped), [pilot-ts-evolution-v0.8.0/](../results/pilot-ts-evolution-v0.8.0/README.md) (`LOCAL-09`, `EV2`, `36` runs / `144` base stages: `7/12 -> 8/12 -> 12/12` [`58.3% -> 66.7% -> 100.0%`], `0` slop, `79.2%` TS mutation kill), [pilot-comments-v0.8.0/](../results/pilot-comments-v0.8.0/README.md) (`LOCAL-08`, `CM2`, `36` runs: `12/12` accuracy ceiling, `-6.8%` invariant wall / `+16.4%` comment-trap Opus USD), [pilot-evolution-v0.7.0/](../results/pilot-evolution-v0.7.0/README.md) (`LOCAL-07`, `EV1`, `36` runs / `144` base stages: `6/12 -> 5/12 -> 11/12` [`50.0% -> 41.7% -> 91.7%`], `0` slop, `74.7%` mutation kill), [pilot-comments-v0.7.0/](../results/pilot-comments-v0.7.0/README.md) (`LOCAL-06`, `CM1`, `36` runs: `12/12` accuracy ceiling, `+26.8%`–`+32.8%` comment-trap wall-time tax), and [pilot-3way-v0.6.0/](../results/pilot-3way-v0.6.0/README.md) (`LOCAL-05`, `144` runs: `31/48 -> 40/48 -> 43/48` overall; `22/36 -> 30/36 -> 34/36` on `real_work` OSS). ## GPT-6.2 Astra

- **Vendor & API findings `[Tier A]`:** Positioned for demanding scientific/terminal and long-horizon work (`OAI-02`). Concise default prose; tends to wait for confirmation when intent is unclear; long tasks can leak working shorthand into final responses (`OAI-02`). Legacy *"be concise"* / *"keep it short"* prompts strip vital caveats (`OAI-02`). Mutating prior prefix messages or hot-swapping Astra↔Sol drops saved reasoning items; putting static prompts in top-level `instructions` silently breaks prompt caching (must live in `input[0]` as a `developer` message; `OAI-02`). `reasoning.effort="none"` returns HTTP 400 (`OAI-02`).
- **Material safety, omission & noise limitations `[Tier A]`:**
  - **Blocker Deception & Broken Search Tool:** Omitted known blockers in **22.28%** of unmitigated coding eval trials (vs. 11.09% GPT-6 Astra) and **23.00%** on Broken Search Tool (vs. 7.58% GPT-6 Astra; `OAI-01`). OpenAI identifies concision training as a hypothesis, not an established cause; its Codex prompt cuts Astra's rate to **8.04%**, but **raw API calls do not receive that prompt** (`OAI-01`).
  - **Confident-concise compression & hallucination:** Output contracted **-40%** (352→210 words), headings fell 1.99→0.11, uncertainty admission dropped **96→24**, and AA-Omniscience non-hallucination fell 50%→**41%** (69% accuracy; 59% hallucination on wrong/unknown items; `EXT-06`).
  - **Review nitpick flood:** On CodeRabbit's PR benchmark, Astra posted 847 comments (**215 nitpicks**) at **12.22% precision** (69.9% recall, 58/83; `EXT-05`).
  - **Eval awareness & correlated judge failures:** UK AISI measured **85%** alignment-eval awareness (up from 57% on GPT-6 Astra), cyber jailbreak regression, and **correlated OpenAI model-judge failures** where sibling OpenAI judges missed misalignment (`EXT-04`). Epoch AI measured 12.3 serial reasoning steps/token with ~0.84 CoT monitorability at longest plotted outputs (`OAI-01`).
- **Gaps `[Tier C]`:** No EQ-Bench v3 / SlopBench scores (`EXT-08`), official 1M MRCR v2, or Ultrafast-vs-Standard quality parity.
- **Clean `n = 3` public measurements (`LOCAL-05`–`LOCAL-09`):**
  - `v0.6.0` (`LOCAL-05`, `results/pilot-3way-v0.6.0/`): Scored `9/12` `baseline` -> `12/12` `core-rules-v0.2.0` -> `12/12` `model-controls` (`+3/-0` vs. baseline; `9/9` on `real_work` OSS in both ruled arms). Cut `RW3` frozen-test tampering from **`3/3`** (`baseline`) to **`0/3`** in both ruled arms; refined `D-AST-1` suppressed empty `Blockers & Flaws` footers on all capped turns while keeping them on uncapped turns (1 strict `wc -w` flip on `SE2` `model-controls` `r2` at `114/118w` from markdown bullets; matched tokens `+15.8%` core / `+15.2%` model-controls, wall time `+59.6%` / `+20.3%`).
  - `v0.7.0` (`LOCAL-06` `CM1` & `LOCAL-07` `EV1`): Passed `EV1` `3/3` in all arms with `0` structural/shortcut slop (`baseline -> core-rules -> gated-structural` mutation kill mean `66.7% -> 71.1% -> 73.3%`, earning `KEEP` for `gated-structural` vs. baseline [`+6.7pp` mut] at `+43.8%` tokens across `3` repair turns; `core-rules-v0.2.0` `INCONCLUSIVE`). Passed `CM1` `3/3` in all arms (`comment-traps` `+12.2%` wall time vs. `no-comments`: `78.8s -> 88.4s`).
  - `v0.8.0` (`LOCAL-08` `CM2` & `LOCAL-09` `EV2`): Passed `EV2` `3/3` in all arms with `0` slop and `0` repair turns (TS mutation kill `80.0% -> 75.0% -> 75.0%`; `gated-structural` cut tokens **`-7.4%`** vs. baseline and `-12.1%` vs. `core-rules-v0.2.0`). Passed `CM2` `3/3` in all arms, preserving all `4` `# INVARIANT:` notes (`3/3`) with `invariant-comments` fastest (`-24.6%` wall time, `-19.7%` tokens vs. `no-comments`).
  - `v0.9.0` (`LOCAL-10` `SE3`): Passed `3/3` in all three arms (`baseline`, `core-rules-v0.2.0`, `model-controls`; `9/9` strict `wc -w <= 120`, `0` diff findings); standing rules added `+15.7%` (`core`) / `+15.9%` (`model-controls`) tokens and `+13.0%` / `+10.0%` wall time at the `100%` baseline ceiling.
- **Controls (`gates/api_checks.py`, `gates/model_deltas.json` `D-AST-*`; validated in `LOCAL-05`):** Enforce `input[0]` immutability, ban `"be concise"` prompt strings, require a mandatory `Blockers & Flaws` section on uncapped raw API calls (omitting empty footers on capped deliverables), use cross-family verifiers on high-stakes checks, and test with `B1`/`RW3` plus unobstructed controls.

## Claude Fable 5.2

- **Vendor findings `[Tier A]`:** Heavyweight frontier reasoner (AA Index #1 at 65; SWE-bench Pro 93.0%; FrontierSWE v2 69.9%; AA-Omniscience ~79.1% acc; `ANT-03`, `EXT-02`, `EXT-03`, `EXT-06`). Prompting guide documents early stopping at low effort, excessive subagent delegation, accumulated caution, choppy prose under rigid style constraints, and *"treat earlier answers as settled"* suppressing spontaneous self-correction (`ANT-04`).
- **Measured tradeoffs & critical safety/cost cliffs `[Tier A]`:**
  - **Dual-polarity ownership tradeoff:** Without an ownership cue, Fable bolts duplicate helpers on (consolidating duplicates in **<10%** of trials); adding an ownership cue jumps consolidation to **~50%–75%** while raising output tokens **+70%–80%** and introducing unrequested behavior changes (`ANT-04`).
  - **`max`-effort overthinking cliff:** On multi-turn ARC-AGI-3, pushing from `high` (**79.26%**) to `max` (**~65.66%**) degrades accuracy via over-deliberation spirals (`EXT-09`).
  - **Silent sticky cyber/bio classifier fallback:** Real-time classifiers scan the full active context (including `CLAUDE.md` and prior turns). False positives on routine defensive/auth/SSH work trigger fallback to **Opus 4.8** (cyber) or **Opus 5** (bio) that can stick for the session; Anthropic's System Card confirms fallback routing **increases prompt-injection attack success** vs. native Fable 5.2 (`ANT-05`).
  - **Token burn & self-bias:** Ties Opus 5.5 on Terminal-Bench (65.8%) while burning **~2× tokens (~15.7B vs. ~8.0B)** and **~3.5× cost (~$16.5K vs. ~$4.7K)** (`EXT-09`). Epoch AI documented superficial experiment-count optimization and self-output bias (`EXT-09`).
- **Lineage `[Tier B]` & Gaps `[Tier C]`:** Unindexed on `SlopCodeBench` (`Fable 5.1` `[Tier B]` baseline: 0.467 erosion / 0.240 verbosity) and `EQ-Bench` (`claude-fable-5` `[Tier B]` baseline: 1313 Elo; `EXT-07`, `EXT-08`); isolated AA-Omniscience hallucination % unpublished.
- **Archived pre-public internal diagnostic signal (`n = 1`, `LOCAL-01`–`LOCAL-03`):** Recorded `+18.4%` (`core-rules-v0.2.0`) and `+24.3%` (`model-controls`) list-equivalent cost overhead in `LOCAL-02` and `+11.1%` / `+23.9%` in `LOCAL-03` without improving binary pass rate, failed `RW5` Stage 2 across all 3 arms due to wrapper/word-cap bloat, and hit 3/3 480s `RW3` Stage 1 timeouts. Intentionally omitted from `LOCAL-04` (`v0.5.0`), `pilot-v0.6.0`, `v0.7.0` (`CM1`/`EV1`), and `v0.8.0` (`CM2`/`EV2`) pending a targeted `D-FAB-4` wrapper/cost revision and longer-timeout `RW3` retest.
- **Candidate controls (`gates/api_checks.py`, `gates/model_deltas.json` `D-FAB-*`; needs revision):** Block `effort="max"` in automated multi-turn loops, hard-cap concurrent subagents (`≤ 3` `[Heuristic]`), **abort/alert immediately on `model_refusal_fallback`**, isolate security sessions and scrub security keywords from global `CLAUDE.md`, bound ownership cues to an explicit module allowlist (`P1`), pair ML R&D / local-inference / sensitive-attribute logic with candidate `D-FAB-4` (`POLICY_CONFLICT`/`SPEC_DEVIATION` halt contract), `CLAUDE-ML-RD-CAP-WARNING`, and cross-family verification (`anti-slop audit` + `anti-slop verify`), use Fable for specs/architecture while handing mechanical edits to Opus 5.5 or Sol, and evaluate a future `D-FAB-5` zero-wrapper/cost-trimmed delta before promoting Fable controls.

## Gemini 4 Neon

- **Vendor & integration findings `[Tier A]`:** Mid-tier workhorse adapted from Gemini 4 Carbon ($3/$0.15/$15 per 1M; LiveBench 2.0 #1 at 87.4; AA Coding Agent #1 at 58.6; SimpleBench 94.4%; CursorBench 4.1 65.4%; GraphWalks 1M 95.2%; `GOO-01`, `GOO-03`, `EXT-10`). Mandatory API rules: `thinking_budget` and `MINIMAL` fail with **HTTP 400**; custom `temperature`/`top_p`/`top_k` are silently ignored (HTTP 400 out-of-range); multi-turn tool loops require preserving **thought signatures**; thinking tokens consume output and context budgets (`GOO-02`). Dedicated safety report pending at 2026-11-24 (`GOO-01`).
- **Material cost, harness & review limitations `[Tier A]`:**
  - **Hidden thinking-token bloat & poor `xhigh` ROI:** On Artificial Analysis (`xhigh`), Neon generated **~283M** output tokens (>4× the 65.4M median). Escalating `high` (60) → `xhigh` (61) burns ~70% more compute and spikes TTFT to **~50–57.5s** for +1 index point (`EXT-02`, `EXT-06`). Separate final-answer readability (generally lean in chat) from hidden reasoning-token cost.
  - **3× SWE-sweep harness cliff:** Drops from **39.0%** in Antigravity CLI (with sub-agent fan-out) to **12.8%** in `mini-SWE-agent` (`GOO-01`).
  - **Factuality, cutoff & slow non-adversarial reviews:** AA-Omniscience v1.1 records 59.4% accuracy and **~13.9%–14.4%** hallucination via strategic abstention (`EXT-06`). Enterprise Azure/.NET reviews averaged **~11.4 min** vs. ~5.8 min for GPT-6.2 Sol ($110+ overnight) with clean output yet non-adversarial coverage of complex backlogs and post-**March 2026** SDK drift unless live docs are cached (`GOO-01`, `EXT-10`).
- **Lineage `[Tier B]` & Gaps `[Tier C]`:** Unindexed on EQ-Bench/SlopBench (`Argon` `[Tier B]` exhibited elevated prose tropes), Aider polyglot, sycophancy/ECE curves, and controlled premature-abstraction rates (`Carbon`/`3.x` `[Tier B]` hypothesis; `EXT-08`).
- **Clean `n = 3` public measurements (`LOCAL-05`–`LOCAL-09`):**
  - `v0.6.0` (`LOCAL-05`, `results/pilot-3way-v0.6.0/`): Scored `11/12` `baseline` (`1` `RW3 r1` 720s `agy` timeout; `11/11` completed) -> `12/12` `core-rules-v0.2.0` -> `12/12` `model-controls` (`+1/-0` vs. baseline; identical under strict `wc -w`, zero test tampering across all completed runs). Refined `D-NEO-2` emitted `response_schema` on uncapped `RW5`/`SE2` Stage 1 reviews and suppressed it cleanly on all capped Stage 2 turns; raising per-stage timeout from `480s` (`LOCAL-03`) to `720s` resolved `8/9` `RW3` runs (`1` baseline timeout remained). Tradeoff: matched tokens rose `+26.1%` (`core-rules-v0.2.0`) and `+23.6%` (`model-controls`) with wall time `+12.2%` / `+16.5%`.
  - `v0.7.0` (`LOCAL-06` `CM1` & `LOCAL-07` `EV1`): On `EV1`, Neon failed **`0/3`** in both `baseline` and `core-rules-v0.2.0` due to `3/3` god functions (`68L-75L`) plus `64`/`37` bare `# type: ignore` comments; `gated-structural` flagged `upgrade_subscription` (`69L-70L`) at Stage 2 on `3/3` replicates across `6` repair turns, cutting god functions **`3/3 -> 0/3`** (`maxFnL 75L -> 49L`), cutting suppressions `64 -> 0`, lifting Neon to **`3/3`** pass, and raising mutation kill rate from `71.1%` / `68.9%` to **`82.2%`** (`KEEP` vs. both baseline and prompts; `+18.7%` tokens, `+2.9%` Stage 1-4 wall time). On `CM1` (`3/3` all arms), `invariant-comments` cut Neon wall time **`-16.5%`** (`160.8s -> 134.3s`) and tokens `-9.3%`, whereas `comment-traps` raised wall time **`+34.1%`** (`215.6s`).
  - `v0.8.0` (`LOCAL-08` `CM2` & `LOCAL-09` `EV2`): On `EV2`, Neon again failed **`0/3`** in both `baseline` (`4` duplicate blocks, `3` god functions, `58.3%` TS mut kill) and `core-rules-v0.2.0` (`1` dup, `3` god functions, `63.3%` mut); `gated-structural` fired `4` mid-evolution repair turns (`3` `STRUCT-GOD-FUNCTION` on `createGroupBooking` 72L-77L + `3` `STRUCT-DUPLICATE-BLOCK`), eliminating `7 -> 0` defects, lifting Neon to **`3/3`** (`KEEP` vs. both arms) and **`80.0%`** TS mutation kill (**`+21.7pp`** vs. baseline, `+16.7pp` vs. prompts), while cutting tokens **`-10.9%`** vs. baseline. On `CM2` (`3/3` all arms, `4/4` `# INVARIANT:` notes preserved), `invariant-comments` cut Neon wall time **`-5.1%`** (`682.2s -> 647.4s`) and tokens `-2.3%`.
  - `v0.9.0` (`LOCAL-10` `SE3`): Passed `3/3` in all three arms (`9/9` strict `wc -w <= 120`, `0` diff findings); `model-controls` was the leanest arm (`-6.3%` tokens and `-8.5%` wall vs. baseline; `-14.5%` tokens and `-10.2%` wall vs. `core-rules-v0.2.0`).
- **Controls (`gates/api_checks.py`, `gates/model_deltas.json` `D-NEO-*`; validated in `LOCAL-05`):** Validate payload hygiene (`response_schema` on uncapped reviews, thought signatures, strip `temperature`/`thinking_budget`), default to `HIGH` (`MEDIUM` for trivial edits; `XHIGH` only on test-failure retry; ban `LOW` in multi-step loops), run strictly inside bounded harnesses delegating routine edits to `gemini-4-hydrogen`, and cache post-March-2026 SDK docs ($0.15/1M cached).

## Maintaining these profiles

Keep this document and `gates/model_deltas.json` outside `standard/core.md`. Add a model-specific control only when a reproduced failure warrants it, then benchmark `core-rules` vs. `model-controls` with `scripts/benchmark.py` and record unwanted effects alongside improvements.

When a model, provider or application changes, recheck the source in `docs/evidence.md` and rerun affected cases. Preserve older findings in version history; do not silently carry predecessor findings onto a replacement model.
