## How to interpret the evidence

- **Vendor documentation** establishes advertised capabilities, API behavior and vendor-reported observations within its stated conditions (`[Tier A]` when testing the named model).
- **External evaluation** supplies another evaluator's measurements (`[Tier A]` on the exact model; `[Tier B]` when from a predecessor/sibling lineage). Independence, task coverage, harness and grading limitations still matter.
- **Editorial reference** supplies values or style guidance, without demonstrating a causal improvement.
- **Proposed control** is this project's inference to test. A published observation does not validate the full seven-rule bundle or any uncalibrated `[Heuristic]` threshold.
- **Clean public measured evaluations (`LOCAL-05`–`LOCAL-09`):** Published under `results/` with isolated per-run `CODEX_HOME`/`HOME`, deterministic pre-hash artifact sanitization, and SHA-256-pinned evidence across `n = 3` replicates per cell (`288` runs total across 5 datasets): `LOCAL-05` (`results/pilot-3way-v0.6.0/`, `144` runs; deterministic checks mechanically verified via `benchmarks/graders/grade_rw3.py`, frozen-test `git diff` tampering, read-only workspace checks, and lexical/`wc -w` counts via `inspect_text_constraints`, with semantic rubric checks scored via isolated LLM-assisted per-case verbatim audit passes committed under `results/pilot-3way-v0.6.0/reviews/`); `LOCAL-06` (`results/pilot-comments-v0.7.0/`, `36` runs; 100% mechanically graded by `benchmarks/graders/grade_cm1.py`); `LOCAL-07` (`results/pilot-evolution-v0.7.0/`, `36` runs / `144` base stages; 100% mechanically graded by `benchmarks/graders/grade_ev1.py` with stdlib AST mutation testing and zero word caps); `LOCAL-08` (`results/pilot-comments-v0.8.0/`, `36` runs; 100% mechanically graded by `benchmarks/graders/grade_cm2.py` across 6 interacting modules); and `LOCAL-09` (`results/pilot-ts-evolution-v0.8.0/`, `36` runs / `144` base stages; 100% mechanically graded by `benchmarks/graders/grade_ev2.py` with JS/TS diff-scoped mutation testing via `gates/mutate.py` and zero word caps).
- **Archived pre-public internal diagnostic (`LOCAL-01`–`LOCAL-04`):** Four `n = 1` local pilots (348 total runs across `v0.2.0`–`v0.5.0`) informed gate and delta scoping and were archived privately off the public repository after pre-launch auditing caught unisolated pre-public Codex `CODEX_HOME` sessions (allowing local `~/.codex/skills/` reads into SHA-256-pinned traces) and early host/temp paths. Rather than silently mutating historical hashes or publishing contaminated Codex traces, `results/` starts with the clean, `CODEX_HOME`-isolated `n = 3` `pilot-3way-v0.6.0` dataset (`LOCAL-05`; see [results/README.md](../results/README.md)). Do not turn published scores or archived `n = 1` diagnostics into general population claims or combine incompatible benchmarks into an overall slop ranking.

### EXT-11

**Empirical Prompt-Bloat, Context-Rot & Multi-Turn Drift Studies** — peer-reviewed/preprint literature (2023–2026).

- **IFScale** (Jaroslawicz et al., Jul 2025, [arXiv:2507.11538](https://arxiv.org/abs/2507.11538)): top models drop to ~68% accuracy at 500 simultaneous constraints with primacy bias.
- **Lost in the Middle** (Liu et al., 2023, [arXiv:2307.03172](https://arxiv.org/abs/2307.03172)) & **Chroma Context Rot** (Jul 2025, 18 models, [trychroma.com/research/context-rot](https://www.trychroma.com/research/context-rot)): non-uniform degradation with input length and distractors.
- **Evaluating AGENTS.md** (Gloaguen et al., Feb/Sep 2026, [arXiv:2602.11988](https://arxiv.org/abs/2602.11988)) vs. **Lulla et al.** (Jan/Mar 2026, [arXiv:2601.20404](https://arxiv.org/abs/2601.20404)): repository context files did not generally improve task success rates while raising inference cost >20% on average (and broad repository overviews were unhelpful), whereas concise operational maps cut median runtime ~28.6% (28.64%) and output tokens ~16.6% (16.58%).
- **Policy Wording Compliance** (Tsuchida et al., Nov 2026, [arXiv:2611.04367](https://arxiv.org/abs/2611.04367)): conditional policy phrasing in `AGENTS.md` followed significantly less reliably than direct prescriptive wording.
- **Multi-Turn Drift** (Laban et al., May 2025, 200K+ convos, [arXiv:2505.06120](https://arxiv.org/abs/2505.06120)): 39% average multi-turn drop driven by premature assumptions and +112% unreliability.

### EXT-13

**Deterministic Harnesses, Over-Mocking, Mutation/Property Verification, Context Hygiene & High-FP Anti-Patterns** (empirical literature and vendor hook/context docs, 2021-2026; live-verified 2026-11-27).

- **Environmental Hardening & Edit-Integrity Hooks:** *Reward Hacking Benchmark* (RHB, Thaman, ICML 2026, [arXiv:2605.02964](https://arxiv.org/abs/2605.02964)): 72% of tool-use reward hacks include explicit CoT rationalizing the shortcut; hardening the environment cut exploits from **6.5% to 0.8%** (**-87.7%** relative, -5.7pp) with flat task success (~83.2% vs. 82.8%). *EvilGenie* (Gabor et al., [arXiv:2511.21654](https://arxiv.org/abs/2511.21654), Claude Code / Codex / Gemini CLI): reserving 30% (max 10) held-out unit tests alone yielded minimal reward-hacking reduction, whereas combining **test-file edit-integrity checks** with an independent judge caught exploits reliably. Vendor lifecycle hooks converge outside the model context window via [Claude Code hooks](https://code.claude.com/docs/en/hooks) (`PreToolUse` / `PostToolUse` / `Stop`, blocking exit `2` with `stderr` feedback; [Anthropic long-running harnesses](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents)), [Antigravity hooks](https://antigravity.google/docs/hooks) (`PreToolUse` / `Stop`), and [Codex `execpolicy`](https://github.com/openai/codex/blob/main/docs/execpolicy.md) + [sandbox](https://github.com/openai/codex/blob/main/docs/sandbox.md) + [Codex hooks](https://learn.chatgpt.com/docs/hooks) (blocking `Stop` hook parity still lags). Implemented as zero-dependency wrappers in `gates/hooks/`.
- **Over-Mocking, Diff-Scoped Mutation & Property-Based Testing:** Hora & Robbes (MSR 2026, [arXiv:2602.00409](https://arxiv.org/abs/2602.00409), 1.2M+ commits across 2,168 TS/JS/Python repos including 48,563 agent commits): coding agents edit test files in **23% vs. 13%** (human) of commits and add mocks in **36% vs. 26%** (**68%** of agent-test repos). Diff-scoped mutation testing validates test strength without runaway noise: Google Critique diff-based mutation + arid-node suppression (Petrović et al., [arXiv:2102.11378](https://arxiv.org/abs/2102.11378), >24,000 developers across >1,000 projects: developer-rated productive mutants rose from **~15%** before filtering to **80%-89%**); Meta ACH (Foster, Harman et al., [arXiv:2501.12862](https://arxiv.org/abs/2501.12862), 10,795 Android Kotlin classes: **73%** engineer acceptance); *MutGen* (Wang et al., IEEE TSE, [arXiv:2506.02954](https://arxiv.org/abs/2506.02954): vanilla LLM tests ~53% vs. **89.5%** mutation-feedback score on HumanEval-Java, while noting some 100%-coverage suites score just 4% mutation); *Test vs Mutant / AdverTest* (Chang et al., [arXiv:2602.08146](https://arxiv.org/abs/2602.08146): **+8.56%** fault detection over SOTA LLM baselines on Defects4J). *PBT-Bench* (Jing et al., NeurIPS 2026, [arXiv:2605.15229](https://arxiv.org/abs/2605.15229), 100 tasks / 40 Python libs / 365 semantic bugs): Hypothesis `@given` scaffolding lifts mid-capability models by **>20 pp** bug recall (complementing [arXiv:2506.18315](https://arxiv.org/abs/2506.18315)).
- **Context Hygiene (Observation Masking vs. Lossy Summarization):** JetBrains Research *The Complexity Trap* (Lindenbauer et al., NeurIPS 2025 DL4C workshop, [arXiv:2508.21433](https://arxiv.org/abs/2508.21433), SWE-bench Verified): replacing stale tool outputs with placeholders (**observation masking**) cuts SWE-agent cost **~52%** while matching or beating LLM summarization (e.g., Qwen3-Coder 480B 54.8% vs. 53.8% raw; hybrid saves an extra 7% vs. masking / 11% vs. summarization), whereas lossy summarization alone obscures failure signals and elongates failed trajectories. `[Vendor]` Anthropic's server-side tool-result clearing (`clear_tool_uses_20250919`, [Anthropic context management](https://claude.com/resources/articles/context-management)) delivered **+29%** agentic eval gain alone and **+39%** with Memory Tool (up to 84% token drop), motivating warning-only `CLAUDE-MISSING-TOOL-CLEAR` and `HARNESS-LOSSY-SUMMARY-ONLY` checks in `gates/api_checks.py`.
- **Cross-Family Judges & Deliberately Skipped High-FP Gates:** Pombal et al. ([arXiv:2604.06996](https://arxiv.org/abs/2604.06996)) show own-family LLM judges are **>50% more likely** to falsely pass failed criteria even on verifiable binary rubrics (IFEval, LiveCodeBench), while *CodeJudgeBench* (Jiang et al., [arXiv:2507.10535](https://arxiv.org/abs/2507.10535)) shows position bias and partial cross-family variance remain, keeping deterministic execution/mutation gates primary. Firouzi & Ghafari ([arXiv:2602.05868](https://arxiv.org/abs/2602.05868), 1,080 LLM samples) found default Semgrep / CodeQL SAST rules matched human security ground truth on only **65% / 61%** of individual samples, warning against unfiltered SAST as blocking post-edit agent hooks. Liang et al. ([arXiv:2304.02819](https://arxiv.org/abs/2304.02819), *Patterns*) measured a **61.22%** false-positive rate for statistical AI-text detectors on non-native English TOEFL essays, supporting our exclusion of statistical "slop" classifiers as CI blockers (alongside intrinsic self-correction prompts without execution feedback, Huang et al., ICLR 2024, [arXiv:2310.01798](https://arxiv.org/abs/2310.01798)).

### EXT-14

**Code Comments, Commented-Out Code Traps & Comment Removal Ablations** (peer-reviewed and preprint empirical studies, 2025-2026; live-verified 2026-11-27).

- **Commented-Out Code Traps:** *Comment Traps: How Defective Commented-out Code Augment Defects in AI-Assisted Code Generation* (Yuan Huang, Yukang Zhou, Xiangping Chen, Zibin Zheng; accepted FSE 2026; [arXiv:2512.20334](https://arxiv.org/abs/2512.20334), published Dec 2025, v2 updated Feb 2026): evaluates GitHub Copilot and Cursor when defective commented-out (CO) code remains in context. Defective CO code increased defective code generation up to **58.17%**, with models actively reasoning to complete partial defect patterns rather than merely copying text verbatim. Even explicit prompt instructions telling the assistant to ignore defective CO code reduced defects by no more than **21.84%**, motivating deterministic removal rather than prompt-only guardrails.
- **Outdated Natural-Language Comments:** *When Comments Mislead: An Empirical Study of Outdated Comments in LLM-Based Code Completion* (Zhikun Xia, Yuan Huang, Xiangping Chen, Zibin Zheng; ASE 2026, Oct 2026; [doi:10.1145/3832783.3834359](https://doi.org/10.1145/3832783.3834359)): demonstrates that outdated or inconsistent natural-language comments exert a systematic misleading effect rather than benign noise, biasing LLM completions toward obsolete historical implementations so outputs look globally plausible while failing specifically in changed regions.
- **Value of Accurate Comments in Bug-Fixing:** *On the Impact of Code Comments for Automated Bug-Fixing: An Empirical Study* (Antonio Vitale, Emanuela Guglielmi, Simone Scalabrino, Rocco Oliveto; accepted ICPC 2026; [arXiv:2601.23059](https://arxiv.org/abs/2601.23059), Jan 2026): evaluated two model families across all training/inference combinations with and without comments. Accurate code comments improved automated bug-fixing accuracy by **up to threefold** when present in both phases without degrading comment-free inputs, and interpretability analysis showed comments explaining method implementation were especially helpful, arguing against blanket "delete all comments" rules.
- **Security Code Review & Comment Stripping:** *Can Adversarial Code Comments Fool AI Security Reviewers* (Scott Thornton; [arXiv:2602.16741](https://arxiv.org/abs/2602.16741), Feb 2026; 100-sample Python/JS/Java benchmark across 8 comment variants and 8 frontier models, 14,012 total trials): adversarial comment manipulations had small, statistically non-significant effects on vulnerability detection (`p > 0.21`), static-analysis cross-referencing reached **96.9%** detection (recovering 47% of baseline misses), and **blind comment stripping reduced detection for weaker models by removing helpful context**.
- **Limitation:** These four studies span different tasks (code completion, automated bug fixing, security review) and different model generations; none tests a single unified comment-style rubric across all frontier coding agents, motivating our controlled local comment ablations in [LOCAL-06](#local-06) (`CM1`) and [LOCAL-08](#local-08) (`CM2`).

### EXT-15

**Empirical AI Code-Smell & Maintainability Debt Taxonomies** (peer-reviewed and preprint empirical studies, 2026; live-verified 2026-11-27).

- **Large-Scale Wild AI Debt Persistence:** *Debt Behind the AI Boom: A Large-Scale Empirical Study of AI-Generated Code in the Wild* (Yue Liu, Ratnadira Widyasari, Yanjie Zhao, Ivana Clairine Irsan, Junkai Chen, David Lo; [arXiv:2603.28592](https://arxiv.org/abs/2603.28592), published Mar 2026, v3 updated Oct 2026): analyzed **302.6k** verified AI-authored commits across **6,299** GitHub repositories covering five AI coding assistants via before/after static analysis. Out of **484,366** distinct AI-introduced issues, **code smells accounted for 89.3%**; **7.5%-14.8%** of each assistant's commits introduced at least one issue, and **22.7%** of tracked AI-introduced issues still survived at the latest repository revision.
- **Architectural Decay & Volume-Quality Inverse Law:** *AI-Generated Smells: An Analysis of Code and Architecture in LLM and Agent-Driven Development* (Yuecai Zhu, Nikolaos Tsantalis, Peter C. Rigby; [arXiv:2605.02741](https://arxiv.org/abs/2605.02741), May 2026): multi-scale audit across single-file algorithms and agent-generated multi-file systems identifying a **Reasoning-Complexity Trade-off** (more capable models generate increasingly bloated and tightly coupled code) and a **Volume-Quality Inverse Law** (code volume strongly predicts structural degradation). Crucially, neither functional correctness nor detailed prompting alone prevented architectural decay.
- **Developer-Attributed AI Issue Taxonomy:** *AI-Generated Code Issues: A Taxonomy from Repository Histories, AI Conversations, and Developer Interviews* (Rosalia Tufano, Nargiz Humbatova, Daniele Bifolco, Gunel Jahangirova, Fiorella Zampetti, Massimiliano Di Penta, Paolo Tonella, Gabriele Bavota; accepted ICSE 2027; [arXiv:2611.32676](https://arxiv.org/abs/2611.32676), Nov 2026): mixed-method study combining **914** manually inspected AI-fix GitHub commits, **299** shared developer-AI conversations, and **20** practitioner/researcher interviews, producing an empirically grounded taxonomy of **87** types of developer-attributed quality issues extending well beyond functional bugs.
- **Build-System Code Smells & Low-Friction Merges:** *AI builds, We Analyze: An Empirical Study of AI-Generated Build Code Quality* (Anwar Ghammam, Mohamed Almukhtar; [arXiv:2601.16839](https://arxiv.org/abs/2601.16839), Jan 2026): mined agent-authored GitHub PRs in the AIDev dataset and identified **364** maintainability and security-related build smells (including missing error handling and hardcoded paths or URLs) alongside occasional smell-removing refactorings, while finding that **>61%** of agentic PRs were approved and merged with minimal human intervention.
- **Limitation:** Static-analyzer smell counts and mined commit attributions are observational measurements of real-world trends, not controlled causal proofs that blocking any single smell class improves downstream feature velocity.
